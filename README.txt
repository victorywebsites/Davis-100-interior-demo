DAVIS 100 INTERIOR — WEBSITE DEMO
==================================

FILES
- index.html: page content and structure
- style.css: responsive visual design
- script.js: mobile navigation and gentle reveal animations

HOW TO OPEN IN SPCK EDITOR (ANDROID)
1. Download and extract Davis-100-Interior-Website-Demo.zip.
2. In Spck, import/open the extracted folder: davis-100-interior-demo.
3. Open index.html and use Preview.
4. An internet connection is needed for the Google Fonts and Unsplash images.
